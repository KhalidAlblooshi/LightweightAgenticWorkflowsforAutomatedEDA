# agentic-eda

**Evaluating Lightweight Agentic Workflows for Automated Exploratory Data Analysis on Tabular Datasets**

MSc Directed Studies — Technical Report Project

---

## Overview

`agentic-eda` implements and compares three automated EDA agent designs:

| Agent | Description |
|---|---|
| **fixed** | Runs a predetermined sequence of tools unconditionally |
| **rule** | Adapts tool selection based on dataset characteristics |
| **llm** | Uses an LLM to select tools; falls back to rule-based if unavailable |

---

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Generate sample datasets
python scripts/download_sample_datasets.py

# 3. Run a single EDA
python main.py --dataset data/sample/students_performance.csv --mode fixed
python main.py --dataset data/sample/students_performance.csv --mode rule
python main.py --dataset data/sample/students_performance.csv --mode llm

# 4. Run all modes on all datasets and produce comparison
python run_all.py
```

## LLM Configuration (optional)

Copy `.env.example` to `.env` and configure your preferred backend:

```bash
cp .env.example .env
# Edit .env with your Ollama or OpenAI credentials
```

If no LLM is available, `--mode llm` automatically falls back to rule-based selection.

---

## Outputs

For each run `outputs/<dataset>/<mode>/` contains:
- `report.md` — Markdown EDA report
- `profile.json` — Dataset profile metadata
- `tool_results.json` — JSON output from each tool
- `tool_log.json` — Timing and error log per tool
- `evaluation.json` — Quality metrics for the run
- `charts/` — Generated PNG visualizations

Aggregate outputs:
- `outputs/evaluation_results.csv` — All run metrics in tabular form
- `outputs/comparison_summary.md` — Cross-mode comparison with discussion
